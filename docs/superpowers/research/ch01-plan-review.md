## 初次评审：Needs changes

1. 历史提交在 done 发送前，与 send 失败时历史不变的要求冲突；要求明确提交边界并覆盖最后 delta、上游 EOF、done send 的失败时点。
2. Task 6 只给 score_cases 写了 TDD，evaluate/smoke 的 HTTP/SSE 行为缺少失败测试；要求能证明验收脚本不会误报通过。
3. 缺失值处理指标和多个增量的真实验收条件不明确；要求给出计数分母、终止事件和上下文连续性的具体判据。

补充建议：限制真实请求与返工轮次；避免重复加入当前 HumanMessage；调研文档更新已说明的模型名及检测到的 Python 版本。

## 修订

- 模型结束只准备待提交消息；响应以 more_body=False 发送唯一 done 终止帧，send 正常返回后无 await 提交一次。边界前失败保留原历史，边界后清理不回滚；ASGI 成功不冒充客户端接收确认。同步更新 spec 的完成语义。
- evaluate/smoke 支持注入 HTTP 客户端，新增 HTTP、分片 SSE、异常终止、超时和失败报告的先红后绿测试。
- 给出三字段准确率、缺失位置准确率、原文约束分母及空集处理；真实 smoke 要求两轮多个 delta、唯一末尾 done、无 error、订单信息连续及固定三键提取。
- 默认 20 条评估加三次 smoke，每轮 23 次模型调用；无自动重试，配置有限 deadline，完整修正复跑不无限循环。
