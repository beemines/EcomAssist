# 全站页面精简

用户原话：“简化一下每个页面，没有用处的地方精简一下，让页面简洁美观”。沿用既定前端Vibe例外，保留浅绿主题、已有功能、真实指标和确认流程，仅调整展示与导航。

范围为本项目聊天、后台首页、待审、观测、主题、分类器验收、RAG评估和样本复核页面；独立Langfuse产品界面不在本次修改内。

精简原则：每页突出主要操作；删除重复口号与说明；技术口径、模型身份、文件清单、计算方法和教学内容使用默认收起的原生details；观测与RAG用页签组织内容；错误、运行状态和提交确认保持可见。聊天侧栏收敛为一个后台入口，后台导航顺序统一。已保存样本复核隐藏无效的提交表单，审核来源仍保留。

不改后端、业务API、费用额度、模型/阈值、语料或数据库。验证以真实页面导航、展开/收起、页签/筛选、输入框行为、JS语法和既有相关离线回归为准；不发送聊天消息、审批知识、创建工单/退款、触发模型训练或收费评估。

## 完成的调整

- 聊天：首页保留欢迎语、三项快捷咨询与输入框；侧栏后台入口合并为一项，去掉重复装饰文案。
- 后台：首页六张紧凑入口卡片，统一六项导航，环境说明按需展开。
- 主题：首屏保留总数、已归类、待归类；日期筛选、模型信息与统计说明折叠，17类图表与原话列表保留。
- 待审：保留状态筛选、原话/证据和审核操作；审核说明默认收起。
- 观测：费用、评估趋势、置信度三个可键盘切换的页签；明细表和方法说明折叠。
- RAG：统一后台导航，检索、回答质量、逐题查看三个页签；运行配置与详细口径默认收起。
- 模型验收：总览突出四项指标，九项流程、矩阵、阈值、逐轮分数、部署和产物清单按需展开。
- 样本复核：收起规则、预测和备注，已保存页面隐藏失效的修改/提交按钮；人工审核备份导出保留，AI代审来源可见。
