在PyCharm打开 `D:\shixi\ecommerce-customer-service\.worktrees\observability-flywheel`。具体解释器和运行配置见[PyCharm指南](ch09-pycharm-acceptance.md)。本机已启动时直接使用现有服务；8006端口占用时不要再启动第二个客服进程。

## 1. 打开四个入口

- 聊天：<http://127.0.0.1:8006/>
- 飞轮待审：<http://127.0.0.1:8006/review>
- 观测与成本：<http://127.0.0.1:8006/observability>

Langfuse使用预置管理员admin@ch09.local登录，密码在本worktree的runtime/langfuse/local.env中LANGFUSE_INIT_USER_PASSWORD字段查看。登录后选组织EcomAssist Local → 项目EcomAssist CH09，再点Observability → Tracing。SDK Key引用sdk.env，别复制进命令输出或截图。

如果首页只显示“开始使用／新组织”，先核对左下角登录邮箱。用户自行注册的个人账号没有自动加入预置组织，应退出后使用上述管理员登录；不要为查看已有链路另建组织。2026-10-21已刷新确认管理员仍能访问原项目与会话95链路。

## 2. 验证完整链路

1. 聊天页点“开启新对话”，发送一条知识问题。可先只读打开已验收会话95对应trace：<http://127.0.0.1:3000/project/ch09-local-project/traces/d6205e14debb348066ed3be91d3d7353>。
2. Langfuse打开这条trace。最上层ch09.execution的Input应是用户原问题，Output应是最终回答，顶部有会话、耗时、Token、美元成本和intent标签。
3. 左侧展开resolve_reference → classify_intent → retrieve_knowledge → confidence_gate → agent。点ChatOpenAI看System/User输入、输出及用量；点query_faq/knowledge.retrieve看检索内容。物流问题的工具来源需是mcp:logistics，仅页面的“查询物流”标签不足以证明MCP。
4. 任意故障要区分上游失败、结构无效与知识不足；故障提示不是知识补齐成功的证据。

## 3. 跑一次人工补知识闭环

1. 使用一个新的、尚未入库的模拟型号，例如“验收用的CH09-A22猫窝磁吸配件要隔多久保养一次？”。CH09-A21已在本次验收补齐，不能再拿它证明首次兜底。
2. 期望先返回资料不足的兜底和“转人工”；在飞轮页点刷新，看到标准问题、次数和AI示例答案。
3. 点问题文字展开。应能看到用户原话、中文入池入口、上海时间、当轮Top3原文、精排分及来源章节；“查看更多”展开其余片段。
4. 可先回聊天对这条回答点👎，等“已反馈”；再刷新审核详情，应该多一个“用户反馈没解决”入口，回捞同一轮片段。同一用户轮次的多入口只计出现1次，详情保留两条原话。
5. 列表点“通过”。弹窗答案已预填AI草稿。人工核实后修改标准化问题、知识分类和核准答案，再点“确认通过”。测试内容必须写明“【验收模拟知识】”，不能把未知AI草稿直接发布为售后政策。
6. 等状态变成“已入库并可检索”。“已审核·待入库”仍不能证明成功；若失败，在详情看原因并针对本条重试。
7. 返回聊天，点“开启新对话”，重问同一问题。答案应来自新知识并带引用。可以用右下反馈检查原轮定位；它不是重新检索一遍。

NULL表示该轮没有检索；空列表[]表示检索零命中；历史证据无法回捞另有提示。不能把三个状态都写成“没有检索”。

## 4. 验证驳回后不会重回待审

在自有模拟缺口点“驳回”，填写原因并“确认驳回”；关闭弹窗后切“驳回”筛选。新会话重问等价问题，等待处理后刷新：应仍是原缺口、次数加1、状态保持驳回，知识库没有新行。本次优惠券缺口review2已从1增至2，可只读查看。

## 5. 查看意图成本与校准

1. 进入观测页，数据来源先选“新标准真实请求”。旧轮未带source_kind标记，需要切“全部（含历史未标注）”才看得到；不能事后认定所有旧数据都是真实模型。
2. 选上海时间范围，结束时间要覆盖刚才的提问；点查询或“重算意图成本账”。重算仅刷新Langfuse统计，不重新问模型。
3. 看总Token、最耗Token意图、请求数、单均、占比。客服、飞轮后台、评估分列。人民币是带日期的标准刊例估算，美元是Langfuse记录值；两者不混加，未知不补零。
4. 页面下部看四信号权重、候选/在用版本、100/200样本分布和扫描曲线。“重算校准报告”只用已存检索数据做本地重算，没有新的模型/嵌入/重排；不热切线上规则。
5. 当前留出误放4/41、误拒9/159，页面应展示风险，不能读成零误放已达标。
